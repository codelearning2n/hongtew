🔥 1. ปฏิกิริยาการเผาไหม้ (Combustion)

เผาไหม้สมบูรณ์ (O2 พอ) → CO2 + H2O + พลังงาน
เผาไหม้ไม่สมบูรณ์ (O2 น้อย) → ได้ CO · formaldehyde · acetic acid [p.10]

วิธีดุลเร็ว ๆ (ทำตามลำดับนี้ไม่มีพลาด):

  1. ดุล C ก่อน → สัมประสิทธิ์ของ CO2 = จำนวน C
  2. ดุล H → สัมประสิทธิ์ของ H2O = จำนวน H ÷ 2
  3. ดุล O ท้ายสุด → นับ O ฝั่งขวาทั้งหมด ÷ 2 = สัมประสิทธิ์ O2
  4. ถ้าได้เศษครึ่ง → คูณทั้งสมการด้วย 2
✅ สูตรลัด
แอลเคน CnH2n+2 + (3n+1)/2 O2 → n CO2 + (n+1) H2O
แอลคีน CnH2n + 3n/2 O2 → n CO2 + n H2O
แอลไคน์ CnH2n−2 + (3n−1)/2 O2 → n CO2 + (n−1) H2O

🧪 2. ปฏิกิริยาประจำแต่ละชนิด

แอลเคนแอลคีน / แอลไคน์
ชนิดปฏิกิริยาเด่นแทนที่ (Substitution)เติม (Addition)
ต้องมีแสง/ความร้อนไหมต้องมี แสงสว่างหรือความร้อนไม่ต้อง เกิดได้ทั้งมืดและสว่าง
ฟอกจางสี KMnO4ไม่ฟอก ❌ฟอกจางสี ✅ (ได้ไกลคอล + ตะกอน MnO2 สีน้ำตาล)
ฟอกสี Br2 ในที่มืดไม่เกิดเกิด สีน้ำตาลแดงจางหายไป
🎯 ข้อสอบชอบถาม "จะแยกแอลเคนกับแอลคีนได้อย่างไร"
ตอบ: หยด Br2 ในที่มืด หรือ KMnO4 — ตัวที่ฟอกจางสีคือแอลคีน/แอลไคน์

ปฏิกิริยาการเติมของแอลคีน 4 แบบ [p.23–29]

แบบเติมอะไรได้อะไร
2.1 HalogenationX2 (Cl2/Br2)ไดฮาโลแอลเคน
2.2 HydrogenationH2 (ตัวเร่ง Ni/Pt)แอลเคน
2.3 HydrohalogenationHX (HCl/HBr/HI)แอลคิลเฮไลด์
2.4 HydrationH2O (เร่งด้วย H2SO4)แอลกอฮอล์
