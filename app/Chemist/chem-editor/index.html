ยังไม่มีอะตอม
Skeletal Formula (สูตรโครงร่าง):
• จุดหักมุม / ปลายเส้น = C
• H ที่ติด C ไม่ต้องเขียน
• เฮเทอโรอะตอม (O, N, S...) ต้องเขียน
• เส้นคู่ = พันธะคู่, เส้นสาม = พันธะสาม
• ▲ Wedge = พันธะชี้หน้า, ▽ Dash = พันธะชี้หลัง
Lewis Structure (โครงสร้างลิวอิส):
• แสดงอะตอมทุกตัวเป็นวงกลมพร้อมสัญลักษณ์
• แสดง H ทุกตัว (implicit H กลายเป็น explicit)
• แสดงเวเลนซ์ (จำนวนพันธะ/เวเลนซ์สูงสุด)
• 🔴 แดง = เกินเวเลนซ์ / 🟠 ส้ม = ยังไม่ครบ
• แสดงอิเล็กตรอนคู่โดดเดี่ยว (lone pair) เป็นจุดคู่
