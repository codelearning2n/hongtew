🧊 การสร้างโมเดล 3 มิติ (Blender) — ฝึกก่อนสอบ

ปลายภาค · ปรนัย 40 ข้อ 20 คะแนน · 60 นาที มีข้อสอบจากใบแนวของอาจารย์ 20 ข้อ

🚦 ยังไม่ได้อ่านสไลด์? เริ่มตรงนี้

ทำตามลำดับนี้ ประมาณ 30–40 นาที แล้วค่อยลงข้อสอบ จะได้ไม่ใช่การเดา

  1. ดู 🖥️ หน้าจอ Blender ก่อน — กดตัวเลขบนรูปเพื่อรู้ว่าปุ่มไหนอยู่ตรงไหน
  2. อ่าน 📋 สรุปกันลืม — โหมด องค์ประกอบ Modifier และ Material ครบในหน้าเดียว
  3. เล่น ⌨️ ฝึกคีย์ลัด ให้จำ G / S / R ได้ก่อน
  4. ค่อยลง 📝 ข้อสอบฝึก — มี 20 ข้อที่มาจากใบแนวของอาจารย์จริง
จุดที่คนไม่ได้อ่านสไลด์พลาดบ่อยที่สุด
• Subdivision Surface = โค้งมน · Solidify = เพิ่มความหนา — สองตัวนี้เป็นตัวลวงของกันและกันในใบแนว
• Image Texture ≠ Image Reference — Texture คือเอารูปไปแปะเป็นผิวโมเดล · Reference คือเอารูปมาวางเป็นแบบตอนปั้น
• Roughness น้อย = มันเงา · มาก = ด้าน (กลับด้านกับที่หลายคนเดา)
• Object Mode = ทำกับทั้งก้อน · Edit Mode = เข้าไปแก้ข้างใน สลับด้วยปุ่ม Tab

💡 จำ G S R ให้ได้ก่อนอย่างอื่น — G Grab (ย้าย) · S Scale (ย่อ-ขยาย) · R Rotate (หมุน) เป็นสามตัวที่ใช้บ่อยที่สุดและออกสอบแน่
⚠️ คู่ที่สลับกันบ่อย — Shift+A = เพิ่มวัตถุใหม่ (Add) กับ Shift+D = ทำสำเนา (Duplicate) · และ Ctrl+R = Loop Cut กับ Ctrl+B = Bevel

🔧 Modifier — ตัวไหนทำอะไร

Modifierหน้าที่
Subdivision Surfaceเพิ่มความโค้งมน ทำให้ผิวเรียบเนียนขึ้น ← ออกสอบ
Solidifyเพิ่มความหนาให้โมเดล ← ออกสอบ
Bevelลบมุมคมให้มนเฉพาะขอบ (คนละอย่างกับ Subdivision)
Arrayทำซ้ำเป็นแถวหลายชิ้น
Mirrorทำซ้ำแบบสะท้อนอีกฝั่ง ใช้ปั้นของที่สมมาตร
Booleanตัด / รวม / หาส่วนซ้อนระหว่างวัตถุสองชิ้น
⚠️ โค้งมน ≠ หนา — โค้งมนคือ Subdivision Surface · หนาคือ Solidify สองตัวนี้เป็นตัวลวงของกันและกันในใบแนว

🎨 Material · Texture · Render

สิ่งที่ถามคำตอบ
Material Propertiesกำหนดสีและพื้นผิวของวัตถุ
Roughnessควบคุมความด้าน — ค่ามาก = ด้าน · ค่าน้อย = มันเงา ← ออกสอบ
Metallicความเป็นโลหะ
Emissionทำให้วัตถุเปล่งแสงเอง
Alphaความโปร่งใส
Image Textureนำรูปภาพมาเป็นพื้นผิวของวัตถุ
UV Editingจัดตำแหน่งภาพ textureลงบนโมเดล (คลี่โมเดลออกเป็นแผ่น)
Image Reference / Blueprintใช้ภาพ 2 มิติเป็นแบบในการปั้น → ช่วยให้สัดส่วนถูกต้อง
Renderแสดงผลภาพสามมิติให้สมจริง (คำนวณแสงเงาออกมาเป็นภาพจริง)
เพิ่มแสงShift+A → Light
⚠️ Image Texture ≠ Image Reference
Texture = เอารูปไปแปะเป็นผิวของโมเดล · Reference = เอารูปมาวางเป็นแบบให้ดูตอนปั้น ไม่ได้ติดไปกับโมเดล

📄 รูปแบบข้อสอบ (จากใบแนว)

ปรนัย 40 ข้อ 20 คะแนน · เลือกคำตอบที่ถูกที่สุดเพียงข้อเดียว ฝนด้วยดินสอ 2B
ถ้าพบข้อผิดพลาดในข้อสอบ อาจารย์ยกผลประโยชน์ให้ผู้สอบ

🖥️ หน้าจอ Blender ของจริง — กดจุดสีส้มบนภาพ

ภาพหน้าจอจริงจากเครื่องเจ้าของ (Blender 3.1.2) · กดปุ่มสลับโหมดเพื่อดูว่า Object Mode กับ Edit Mode ต่างกันตรงไหน — ใบแนวออกเรื่องนี้ 3 ข้อ

จอมือถือย่อภาพลงเกือบ 4 เท่า ตัวหนังสือในภาพจะอ่านไม่ออก — กดปุ่มนี้ (หรือแตะที่ภาพซูมข้างล่าง) เพื่อดูขนาดจริง
👆 กดจุดสีส้มบนภาพเพื่อดูว่าโซนนั้นคืออะไร ใช้ทำอะไร และตรงกับใบแนวข้อไหน

🎛️ แถบโหมด — บน Object · ล่าง Edit

พอเข้า Edit Mode จะมีปุ่มสามอันโผล่มาต่อจากดรอปดาวน์ = เลือก Vertex / Edge / Face (กด 1 · 2 · 3 ก็ได้)
และเมนูเปลี่ยนจาก Add Object เป็น Add Mesh Vertex Edge Face UV

🧰 แถบเครื่องมือซ้าย — ซ้าย Object · ขวา Edit

⭐ Edit Mode มีเครื่องมือเยอะกว่าเป็นเท่าตัว — เครื่องมือที่โผล่มาเพิ่มคือพวกที่ใช้แก้รูปทรง เช่น Extrude · Inset · Bevel · Loop Cut · Knife
นี่คือเหตุผลว่าทำไมใบแนวข้อ 20 ตอบว่า "ควรใช้ Edit Mode ในการแก้ไขรูปทรงของโมเดล"

🗂️ แท็บ Workspace บนสุด

⭐ UV Editing เป็นแท็บบนแถบนี้ ไม่ใช่ปุ่มในเมนู — ใบแนวข้อ 16 ถามว่า UV Editing ใช้ทำอะไร ตอบ จัดตำแหน่งภาพ Texture บนโมเดล
สังเกตว่าแถบนี้อยู่แถวเดียวกับ File Edit Render Window Help ไม่ได้แยกแถว
