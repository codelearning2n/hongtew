🔑 สูตรสำคัญ (ไว้เปิดดูเร็ว ๆ)

ฟลักซ์แม่เหล็ก (θ วัดจากระนาบ)Φ = B·A·sinθ
แรงบนประจุเคลื่อนที่F = q·v·B·sinθ
แรงบนลวดมีกระแสF = B·I·L·sinθ
สนามรอบลวดตรงB = μ₀I/(2πR), μ₀/2π = 2×10⁻⁷
โมเมนต์ขดลวด (max ที่ θ=0)M = N·I·A·B·cosθ
มอเตอร์ (แรงดันดันกลับ)I = (E − e)/(R + r)
หม้อแปลงV₁/V₂ = N₁/N₂ = I₂/I₁
ไฟฟ้ากระแสสลับE = Eₘ·sin(ωt), ω = 2πf
ค่ายังผล (rms)V_rms = Vₘ/√2
รีแอกแตนซ์X_C = 1/(2πfC), X_L = 2πfL
กำลังไฟฟ้า ACP = V·I·cosφ = I²·R
