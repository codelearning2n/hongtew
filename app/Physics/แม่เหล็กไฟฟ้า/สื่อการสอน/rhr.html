F = q·v·B·sinθ — นิ้วทั้งสี่ชี้ตามทิศ v, หันฝ่ามือรับทิศ B, หัวแม่มือชี้ทิศ F (ถ้าเป็นประจุลบ กลับทิศ)

ทิศความเร็ว v
ทิศสนามแม่เหล็ก B
θ = 90°
v = ความเร็ว B = สนามแม่เหล็ก F = แรง

ขนาดของแรง

F = q · v · B · sinθ

แรงบนลวดตัวนำที่มีกระแส

F = B·I·L·sinθ — นิ้วทั้งสี่ชี้ตามทิศ I, หันฝ่ามือรับทิศ B, หัวแม่มือชี้ทิศ F

ทิศกระแส I
ทิศสนามแม่เหล็ก B
θ = 90°
I = กระแส B = สนามแม่เหล็ก F = แรง

ขนาดของแรง

F = B · I · L · sinθ
0 N

สนามแม่เหล็กรอบลวดตรง (กฎของเออร์สเตด)

B = μ₀I/(2πR), μ₀/2π = 2×10⁻⁷ — กำมือขวารอบลวด หัวแม่มือชี้ทิศกระแส I นิ้วทั้งสี่วนตามทิศสนาม B

สรุปกฎมือขวา

1) อนุภาคมีประจุ: นิ้วชี้ตามทิศ v → ฝ่ามือรับทิศ B → หัวแม่มือ = F (ประจุลบกลับทิศ)

2) ลวดมีกระแส: นิ้วชี้ตามทิศ I → ฝ่ามือรับทิศ B → หัวแม่มือ = F

3) สนามรอบลวด: กำมือ หัวแม่มือชี้ทิศ I → นิ้ววนรอบ = ทิศ B

กรณีแรงเป็นศูนย์: q = 0 (เช่นนิวตรอน), v = 0 (อยู่นิ่ง), หรือ v ขนานกับ B (sinθ=0)
