⚡ เปรียบเทียบ: ไฟฟ้าสถิต vs ไฟฟ้ากระแส

🌩️ ไฟฟ้าสถิต (Static Electricity)

ประจุสะสม: 0 หน่วย

VS

🔋 ไฟฟ้ากระแส (Current Electricity)

กระแส: 0.00 A (ไหลต่อเนื่อง)

📋 ตารางเปรียบเทียบ

คุณสมบัติ🌩️ ไฟฟ้าสถิต🔋 ไฟฟ้ากระแส
การเกิดเสียดสี / เหนี่ยวนำแหล่งกำเนิด (แบตเตอรี่, เครื่องปั่นไฟ)
ลักษณะประจุสะสมบนผิววัตถุ อยู่นิ่งไหลต่อเนื่องในตัวนำ
แรงดันสูงมาก (หลายพัน V)ต่ำ-ปานกลาง (1.5 - 220 V)
กระแสน้อยมาก / ชั่วขณะต่อเนื่อง คงที่
ระยะเวลาชั่วขณะ (คายทันที)ต่อเนื่องตราบที่วงจรปิด
การใช้งานเครื่องถ่ายเอกสาร, ฟ้าผ่าเครื่องใช้ไฟฟ้าทั่วไป
อันตรายช็อตแรงแต่สั้นอันตรายถ้ากระแสสูง

🔌 กระแสไฟฟ้า (Electric Current)

นิยาม

กระแสไฟฟ้า คือ อัตราการเคลื่อนที่ของประจุไฟฟ้าผ่านพื้นที่หน้าตัดในหนึ่งหน่วยเวลา

I = Q / t
I = กระแสไฟฟ้า (A) Q = ประจุไฟฟ้า (C) t = เวลา (s)

ในโลหะ: I = nevdA

n = ความหนาแน่นของ e⁻ อิสระ (ตัว/m³) e = ประจุอิเล็กตรอน = 1.6 × 10⁻¹⁹ C vd = ความเร็วลอยเลื่อน (m/s) A = พื้นที่หน้าตัด (m²)

🎬 แอนิเมชัน: การไหลของอิเล็กตรอนในตัวนำ

กระแส I = 1.20 A

🧮 เครื่องคำนวณ: กระแสไฟฟ้า

I = 2.00 A

📐 กฎของโอห์ม (Ohm's Law)

กฎของโอห์ม

กระแสไฟฟ้า (I) แปรผันตรงกับแรงดันไฟฟ้า (V) และแปรผกผันกับความต้านทาน (R)

V = I × R

🔺 สามเหลี่ยมโอห์ม — คลิกเพื่อหาค่า

คลิกที่ V, I, หรือ R เพื่อดูสูตร

📈 กราฟ V-I (Interactive)

ความชันของกราฟ = 1/R (ความนำไฟฟ้า G)

🧮 เครื่องคำนวณกฎของโอห์ม

เลือกค่าที่ต้องการหา:

🔧 ความต้านทาน (Resistance)

ปัจจัยที่มีผลต่อความต้านทาน

R = ρL / A
R = ความต้านทาน (Ω)ρ = สภาพต้านทาน (Ω·m) L = ความยาว (m)A = พื้นที่หน้าตัด (m²)

🎛️ จำลอง: เปลี่ยนขนาดลวดดูค่า R

A = 7.854×10⁻⁷ m² | R = 0.0438 Ω

🔗 การต่อตัวต้านทาน

🔵 อนุกรม (Series)

Rรวม = R₁ + R₂ + R₃ + ...
  • กระแสเท่ากันทุกตัว: Iรวม = I₁ = I₂ = I₃
  • แรงดันรวม: Vรวม = V₁ + V₂ + V₃

🔴 ขนาน (Parallel)

1/Rรวม = 1/R₁ + 1/R₂ + 1/R₃ + ...
  • แรงดันเท่ากัน: Vรวม = V₁ = V₂ = V₃
  • กระแสรวม: Iรวม = I₁ + I₂ + I₃

🎬 จำลองวงจรอนุกรม & ขนาน

🔋 แรงเคลื่อนไฟฟ้า (EMF)

สูตรแรงเคลื่อนไฟฟ้า

E = V + Ir หรือ V = E - Ir
E = แรงเคลื่อนไฟฟ้า (V)V = ความต่างศักย์ที่ขั้วเซลล์ (V) I = กระแสไฟฟ้า (A)r = ความต้านทานภายใน (Ω)R = ความต้านทานภายนอก (Ω)
I = E / (R + r)

🔋 จำลอง: เซลล์ไฟฟ้ากับความต้านทานภายใน

🔋 การต่อเซลล์ไฟฟ้า

ต่อแบบเสริม (อนุกรม)

Eรวม = E₁ + E₂ + ... + En

rรวม = r₁ + r₂ + ... + rn

ถ้าเซลล์เหมือนกัน n ก้อน:

Eรวม = nE, rรวม = nr

ต่อแบบขนาน

Eรวม = E (เท่ากับแต่ละเซลล์)

rรวม = r / n

🧮 เครื่องคำนวณ: การต่อเซลล์

📊 กฎของเคอร์ชอฟฟ์ (Kirchhoff's Laws)

KVL — กฎแรงดัน

ΣV = 0 (รอบวงปิด)

ผลรวมของความต่างศักย์ไฟฟ้ารอบวงปิดใดๆ ย่อมมีค่าเป็นศูนย์

KCL — กฎกระแส

ΣIเข้า = ΣIออก

ณ จุดใดๆ กระแสไฟฟ้าที่ไหลเข้าย่อมเท่ากับกระแสที่ไหลออก

🎬 แอนิเมชัน KCL: กระแสเข้า = กระแสออก

I₄ ออก = 4.0 A | ΣIเข้า = ΣIออก ✓

🌉 Wheatstone Bridge

วงจรบริดจ์สมดุล: เมื่อ R₁/R₂ = R₃/R₄ จะไม่มีกระแสไหลผ่าน R₅ (กัลวาโนมิเตอร์)

💡 พลังงานไฟฟ้า & กำลังไฟฟ้า

สูตรพลังงานไฟฟ้า

W = QV = IVt = I²Rt = V²t/R

สูตรกำลังไฟฟ้า

P = W/t = IV = I²R = V²/R

หน่วยไฟฟ้า (Unit)

1 Unit = 1 kW·hrค่าไฟ = Unit × ราคาต่อหน่วย
