คณิตเก็บตก — อธิบายง่ายสุดๆ

3 บทที่เหลือ เล่าด้วยของจริงรอบตัว: โดมิโน (อุปนัย), ตัดเค้กเป็นชิ้น (ปริพันธ์เชิงตัวเลข), เดินบนภูเขา (หลายตัวแปร) 👇

🁢อุปนัยเชิงคณิต = "ล้มโดมิโน"

🧒 อธิบายแบบเด็กประถม
นึกถึงโดมิโนเรียงยาวเป็นล้านตัว เราอยากรู้ว่า "ล้มหมดทุกตัวไหม" ไม่ต้องไปดูทีละตัวให้เมื่อย แค่เช็ค 2 อย่าง:
① ผลักตัวแรกล้มได้จริง (เริ่มต้น n=1)   ② ทุกตัวที่ล้ม จะชนตัวถัดไปให้ล้มต่อ (k ล้ม → k+1 ล้ม)
ถ้าทั้ง 2 ข้อจริง → ล้มหมดทุกตัวแน่นอน! นั่นแหละคืออุปนัย

📝เขียนพิสูจน์ยังไง (3 ขั้นตายตัว)

สูตรท่อง 3 ขั้น
  1. ขั้นฐาน (Basis): แทน n=1 แล้วเช็คว่าจริง ← ผลักตัวแรก
  2. ขั้นสมมติ (Hypothesis): สมมติว่า n=k จริง ← เชื่อว่าตัวที่ k ล้ม
  3. ขั้นพิสูจน์ (Step): ใช้ข้อ 2 ทำให้ n=k+1 จริง ← ตัว k ชนตัว k+1 ล้ม
ตัวอย่างคลาสสิกพิสูจน์ว่า 1+2+3+…+n = n(n+1)/2
▸ ดูวิธีทำทีละขั้น
ขั้นฐาน n=1: ซ้าย = 1 , ขวา = 1(2)/2 = 1 → เท่ากัน ✓ผลักตัวแรกล้มได้
ขั้นสมมติ n=k: สมมติ 1+2+…+k = k(k+1)/2 (เชื่อก่อนว่าจริง)
ขั้นพิสูจน์ n=k+1: เอาสมมติมา +(k+1) ทั้งสองข้างเพิ่มพจน์ถัดไป
ซ้าย = [k(k+1)/2] + (k+1) = (k+1)[k/2 + 1] = (k+1)(k+2)/2
ขวา (แทน k+1 ในสูตร) = (k+1)(k+2)/2 → เท่ากัน! ✓ตัว k ชนตัว k+1 ล้มได้ → จบ พิสูจน์เสร็จ
เคล็ดสอบ: ขั้นพิสูจน์เกือบทุกข้อ = "เอาสมการขั้นสมมติมา บวก/คูณ พจน์ถัดไป (k+1) ทั้งสองข้าง" แล้วจัดรูปให้เหมือนสูตรที่แทน k+1

      ⛰️อนุพันธ์ย่อย = "เดินบนภูเขา ทีละทิศ"

      🧒 อธิบายแบบเด็กประถม
      ฟังก์ชัน 2 ตัวแปร f(x,y) เหมือนความสูงของภูเขา ที่ขึ้นกับว่าเรายืนตรงไหน (x = ทิศตะวันออก, y = ทิศเหนือ)
      ∂f/∂x = "ถ้าเดินไปทาง x อย่างเดียว (ทิศเหนือหยุดนิ่ง) พื้นชันแค่ไหน" → เลยต้อง แช่แข็ง y ให้เป็นค่าคงที่ แล้วดิฟ x ตามปกติ
      ∂f/∂y = สลับกัน: แช่แข็ง x แล้วดิฟ y
      f(x,y) = x²y + y³
      —
      กฎเหล็ก: ตัวแปรที่ "แช่แข็ง" ให้คิดเป็นแค่ตัวเลขธรรมดา (เช่น y เป็น 5) — พจน์ที่มีแต่ตัวแช่แข็งล้วน อนุพันธ์เป็น 0 (เพราะเป็นค่าคงที่)

      ✏️ ฝึกโจทย์ — อนุพันธ์ย่อย

      —

        🧶สมการเชิงอนุพันธ์ = "แยกของพันกัน แล้วคลี่"

        🧒 อธิบายแบบเด็กประถม
        สมการที่มี dy/dx (อัตราการเปลี่ยน) ปนกันอยู่ — เป้าหมายคือหา y ออกมาเป็นฟังก์ชันของ x
        วิธีง่ายสุด (แยกตัวแปร) เหมือนแยกถุงเท้าคนละสี: จับ y ทั้งหมดไปข้างซ้าย, x ทั้งหมดไปข้างขวา แล้วใส่ ∫ (อินทิเกรต) ทั้งสองข้าง → ได้คำตอบ! (อย่าลืม +C)
        3 ขั้น แยกตัวแปร
        1. ย้าย: dy/dx = (ก้อน x)(ก้อน y) → (1/ก้อน y) dy = (ก้อน x) dx
        2. อินทิเกรตทั้งสองข้าง: ∫ … dy = ∫ … dx
        3. ใส่ +C ข้างเดียวพอ แล้วจัดรูปหา y
        แบบที่เจอบ่อยสุดแก้ dy/dx = ky (การเติบโต/สลายตัว เช่น ประชากร, สารกัมมันตรังสี)
        ▸ ดูวิธีทำ
        แยก: (1/y) dy = k dxy ไปซ้าย, x(กับ k) ไปขวา
        ∫(1/y)dy = ∫k dx → ln|y| = kx + C
        ยกกำลัง e ทั้งสองข้าง: y = e^(kx+C) = e^C · e^(kx)
        y = A·e^(kx) (ให้ A = e^C เป็นค่าคงที่)นี่คือสูตรการเติบโตแบบทวีคูณ
        แยกตัวแปรตรงๆแก้ dy/dx = x/y
        ▸ ดูวิธีทำ
        แยก: y dy = x dxคูณ y ไขว้ขึ้นมา
        ∫y dy = ∫x dx → y²/2 = x²/2 + C
        y² = x² + C′ (คูณ 2 ตลอด, C′=2C)
        ง่ายสุด (อินทิเกรตตรงๆ)แก้ dy/dx = 6x² + 2
        ▸ ดูวิธีทำ
        ข้างขวาไม่มี y → แค่อินทิเกรตข้างขวา: y = ∫(6x²+2)dx
        y = 2x³ + 2x + C
