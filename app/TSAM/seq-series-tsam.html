ลำดับและอนุกรม

สอนละเอียดทุกหัวข้อ มีสูตร เทคนิคจำ (รวม ส่วนชนะ/เศษชนะ) ตัวอย่างทำให้ดูทีละขั้น + ฝึกเอง 👇

🔢ลำดับคืออะไร

ลำดับ = ชุดตัวเลขเรียงกันมีกฎ · พจน์ที่ n เขียนว่า an (พจน์ทั่วไป / general term) มี "..." ต่อท้าย = ลำดับอนันต์, ถ้าจบ = ลำดับจำกัด

ตัวอย่างที่ 2 (อ.)กำหนด an = 2n² − 3n จงหา a₁ และ a₂
▸ ดูวิธีทำ
a₁ = 2(1)² − 3(1) = 2 − 3 = −1แทน n=1
a₂ = 2(2)² − 3(2) = 8 − 6 = 2แทน n=2

ลองเล่น: ลำดับเลขคณิต vs เรขาคณิต

ลากดูว่าเปลี่ยน a₁, d/r แล้วลำดับวิ่งยังไง — เลขคณิตบวกเพิ่มคงที่ (เส้นตรง) · เรขาคณิตคูณคงที่ (โค้งชัน)

พจน์แรก a₁2
ผลต่างร่วม d3
พจน์ทั่วไป
an = 2 + (n−1)(3)
2, 5, 8, 11, …

📐สูตรที่ต้องจำ — ชนิดของลำดับ

เลขคณิต (Arithmetic) เพิ่ม/ลดคงที่โดยการบวก d
an = a₁ + (n−1)d  ,  d = an+1 − an
เรขาคณิต (Geometric) เพิ่ม/ลดคงที่โดยการคูณ r
an = a₁·rn−1  ,  r = an+1 / an
ฮาร์มอนิก (Harmonic) ลำดับที่ส่วนกลับ (1/an) เป็นเลขคณิต
bn = 1/an เป็นเลขคณิต
เทคนิค อ.: เจอลำดับ → ลองลบคู่ติดกัน (ได้ d เท่ากัน = เลขคณิต) ถ้าไม่ ลองหารคู่ติดกัน (ได้ r เท่ากัน = เรขาคณิต) ถ้ายังไม่ ลองกลับเศษส่วน 1/an แล้วเช็คว่าเป็นเลขคณิตไหม (= ฮาร์มอนิก)
ตัวอย่างที่ 12 (อ.)ลำดับเลขคณิต มี a₄ = 20 และ a₁₀ = 38 จงหาพจน์ทั่วไป
▸ ดูวิธีทำ
a₄ = a₁+3d = 20 ... (1)   ,   a₁₀ = a₁+9d = 38 ... (2)เขียนสองสมการจากสูตร an=a₁+(n−1)d
(2)−(1): 6d = 18 → d = 3ลบกันกำจัด a₁
แทนใน (1): a₁ + 3(3) = 20 → a₁ = 11
an = 11 + (n−1)(3) = 3n + 8
ตัวอย่างที่ 24 (อ.)ลำดับเรขาคณิต มี a₃ = 2 และ a₇ = 2592 จงหาพจน์ทั่วไป
▸ ดูวิธีทำ
a₃ = a₁r² = 2 ... (1)   ,   a₇ = a₁r⁶ = 2592 ... (2)
(2)÷(1): r⁴ = 2592/2 = 1296 → r⁴ = 6⁴ → r = 6หารกำจัด a₁ — เรขาใช้ "หาร" (ต่างจากเลขคณิตที่ "ลบ")
a₁(6²) = 2 → a₁ = 2/36 = 1/18
an = (1/18)·6n−1

✏️ ฝึกโจทย์ — ลำดับ

—

    ⭐ลิมิตของลำดับอนันต์ — "ส่วนชนะ / เศษชนะ / เสมอ"

    ถาม "พอ n วิ่งไป ∞ แล้ว an เข้าหาเลขอะไร" · ถ้าได้เลขจริง = ลู่เข้า (convergent), ถ้าหาค่าไม่ได้/พุ่ง ∞ = ลู่ออก (divergent)

    กฎพื้นฐาน 3 ข้อ (จดจากบอร์ด อ.)

    limn→∞ C = C
    ค่าคงที่ → ตัวมันเอง · เช่น lim 2 = 2
    limn→∞ nk = หาค่าไม่ได้ (k>0)
    n ยกกำลังบวก → พุ่ง ∞ (ลู่ออก) · เช่น lim n⁴ = หาค่าไม่ได้
    limn→∞ 1/nk = 0 (k>0)
    1 หารด้วยตัวโตขึ้นเรื่อยๆ → 0 · เช่น lim 1/n⁴ = 0

    ⚖️เครื่องตัดสิน "ส่วนชนะ/เศษชนะ" (ลองเล่น)

    เศษส่วนพหุนาม → ดูแค่ ดีกรีสูงสุด บนกับล่าง ตัวไหนชนะ ลองปรับดีกรี/สัมประสิทธิ์ดูคำตัดสินสดๆ

    n4 + พจน์เล็กๆ เศษ ดีกรี 4
    n4 + พจน์เล็กๆ ส่วน ดีกรี 4
    เสมอ → เศษ/ส่วน= 9/1 = 9
    แทน n =ค่าโดยประมาณ
    สรุปกฎทอง: เศษชนะ (ดีกรีบน>ล่าง) → หาค่าไม่ได้ (ลู่ออก ∞) · ส่วนชนะ (ดีกรีล่าง>บน) → 0 · เสมอ (ดีกรีเท่ากัน) → เอาสัมประสิทธิ์ตัวหน้า เศษ/ส่วน

    ตัวอย่างจากบอร์ด อ.

    เศษส่วน • ส่วนชนะlimn→∞ (n³ + 4)/(n⁴ + n²)
    ▸ ดูวิธีทำ
    ดีกรีบน = 3, ดีกรีล่าง = 4 → ส่วนชนะตัวล่างโตเร็วกว่า
    ส่วนชนะ → = 0 (ลู่เข้า)เหมือน 1/n → 0
    เศษส่วน • เสมอlimn→∞ (9n⁴ + 700)/(n⁴ + n²)
    ▸ ดูวิธีทำ
    ดีกรีบน = 4 = ดีกรีล่าง → เสมอ
    เอาสัมประสิทธิ์ตัวหน้า เศษ/ส่วน = 9/1 → = 9พจน์ 700 กับ n² เล็กเมื่อเทียบ n⁴ ตัดทิ้งได้
    เศษชนะlimn→∞ (2n³ + 1)/(n² + 5)
    ▸ ดูวิธีทำ
    ดีกรีบน = 3 > ล่าง = 2 → เศษชนะ
    เศษชนะ → หาค่าไม่ได้ (ลู่ออก, → ∞)
    ระวัง! สลับเครื่องหมายlimn→∞ (−1)n+1 (เช่น 1, −1, 1, −1, …)
    ▸ ดูวิธีทำ
    ค่ามันเด้งไป-มา 1, −1, 1, −1 ไม่เข้าหาเลขใดเลข
    หาค่าไม่ได้ → ลู่ออก(หน้าที่หนูจดไว้สีแดง) เพราะเปลี่ยนไปเรื่อยๆ ไม่นิ่ง

    ✏️ ฝึกโจทย์ — ลิมิตของลำดับ

    —

      Σสัญลักษณ์ซิกม่า — "หลายตัวบวกกัน เขียนสั้นๆ"

      ∑i=1n ai = a₁ + a₂ + … + an · ตัวล่าง=เริ่มที่ i เท่าไร, ตัวบน=จบที่เท่าไร

      สมบัติของ Σ
      ∑i=1n c = n·c
      ∑i=1n c·ai = c·∑ai  (ดึงค่าคงที่ออกได้)
      ∑(ai ± bi) = ∑ai ± ∑bi
      สูตรผลบวกสำเร็จ (ใช้บ่อย)
      ∑i=1n i = n(n+1)/2
      ∑i=1n i² = n(n+1)(2n+1)/6
      ∑i=1n i³ = [n(n+1)/2]²
      ตัวอย่างที่ 36 (อ.)หาค่า ∑i=36 (i² + 1)
      ▸ ดูวิธีทำ
      แทน i = 3,4,5,6 ทีละตัวเริ่ม 3 จบ 6 = 4 พจน์
      (3²+1)+(4²+1)+(5²+1)+(6²+1) = 10 + 17 + 26 + 37
      = 90
      ตัวอย่างที่ 37 (อ.)เขียน 1 + 4 + 9 + 16 + 25 + 36 ในรูป ∑
      ▸ ดูวิธีทำ
      สังเกต: 1², 2², 3², …, 6² → พจน์ทั่วไป i²มองหาแพตเทิร์น
      มี 6 พจน์ เริ่ม i=1 → ∑i=16 i²

      ✏️ ฝึกโจทย์ — ซิกม่า

      —

        ➕อนุกรม — เอาพจน์ในลำดับมาบวกกัน

        Sn = ผลบวก n พจน์แรก = a₁ + a₂ + … + an

        อนุกรมเลขคณิต เทคนิค อ.: "จับคู่หัว-ท้ายให้ผลบวกเท่ากัน"
        Sn = (n/2)(a₁ + an)
        หรือ Sn = (n/2)[2a₁ + (n−1)d]
        ใช้สูตรบนเมื่อรู้พจน์แรก-สุดท้าย · ใช้สูตรล่างเมื่อรู้ a₁ กับ d
        อนุกรมเรขาคณิต
        Sn = a₁(rn − 1)/(r − 1)  (r ≠ 1)
        ถ้า r<1 พลิกเป็น a₁(1 − rn)/(1 − r) ให้เลขบวกอ่านง่าย
        ตัวอย่างที่ 53 (อ.)หาผลบวก 7 พจน์แรกของอนุกรมจากลำดับ 7, 15, 23, …
        ▸ ดูวิธีทำ
        เลขคณิต a₁=7, d=8 → หา a₇ = 7+(7−1)(8) = 7+48 = 55
        S₇ = (7/2)(a₁+a₇) = (7/2)(7+55) = (7/2)(62)
        = 7 × 31 = 217
        ตัวอย่างที่ 55 (อ.)หาค่า 2 + 6 + 10 + … + 38
        ▸ ดูวิธีทำ
        a₁=2, d=4, an=38 → หา n: 38 = 2+(n−1)4 → 36=4(n−1) → n=10
        S₁₀ = (10/2)(2+38) = 5(40)
        = 200
        ตัวอย่างที่ 61 (อ.)หาผลบวก 8 พจน์แรกของ 1, 2, 4, 8, …
        ▸ ดูวิธีทำ
        เรขาคณิต a₁=1, r=2, n=8
        S₈ = a₁(r⁸−1)/(r−1) = 1(2⁸−1)/(2−1) = (256−1)/1
        = 255

        ✏️ ฝึกโจทย์ — อนุกรม

          ∞อนุกรมอนันต์ — บวกไม่จบ แต่บางทีได้เลขจริง!

          ดูผลบวกย่อย Sn เมื่อ n→∞ · ถ้า lim Sn = S (เลขจริง) = ลู่เข้า หาผลบวกได้ · ถ้าหาไม่ได้ = ลู่ออก

          เช็คเร็ว (เงื่อนไขจำเป็น)
          ถ้า limn→∞ an ≠ 0 → ลู่ออกแน่นอน
          เช่น 1+3+5+… พจน์ไม่เข้า 0 → ลู่ออก · (แต่ an→0 ยังไม่การันตีลู่เข้า)
          ★ เรขาคณิตอนันต์ (ออกสอบบ่อยสุด)
          ถ้า |r| < 1 → ลู่เข้า   S = a₁/(1 − r)
          ถ้า |r| ≥ 1 → ลู่ออก

          ลองเล่น: เลื่อน r ดูว่าลู่เข้าหรือระเบิด

          พจน์แรก a₁1
          อัตราส่วน r0.50
          สถานะ
          —
          ผลบวกอนันต์ S
          —
          ตัวอย่างที่ 71-2 (อ.)3/10 + 3/100 + 3/1000 + … หาผลบวก
          ▸ ดูวิธีทำ
          เรขาคณิต a₁ = 3/10, r = (3/100)/(3/10) = 1/10|r|=0.1 < 1 → ลู่เข้า
          S = a₁/(1−r) = (3/10)/(1 − 1/10) = (3/10)/(9/10)
          = 3/9 = 1/3นี่คือเหตุผลว่าทำไม 0.333… = 1/3
          ลู่ออก1 + 3 + 5 + … + (2n−1) + …
          ▸ ดูวิธีทำ
          นี่คือเลขคณิต (d=2) พจน์ an=2n−1 → lim an = ∞ ≠ 0
          ลู่ออก (อนุกรมเลขคณิตอนันต์ลู่ออกเสมอ ยกเว้นทุกพจน์เป็น 0)
