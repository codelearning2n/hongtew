ฟังก์ชันผกผัน & ฟังก์ชันอดิศัย

inverse · exp/log · ln · ตรีโกณผกผัน · ไฮเพอร์โบลิก — คลังโจทย์ไล่ระดับ ง่าย → กลาง → ยาก → โหด · เฉลยทีละสเต็ป + นัยใบ้ · จำคะแนนอัตโนมัติ

🎯 แก่นแท้ 30 วินาที — สูตรที่ต้องมีในหัว

▶
ฟังก์ชันผกผัน หา f⁻¹: สลับ x↔y แล้วแก้หา y กราฟ f⁻¹ = สะท้อน f ผ่านเส้น y = x (f⁻¹)'(b) = 1 / f'(a) เมื่อ f(a)=b
exp ↔ log (ผกผันกัน) e^(ln x) = x ln(eˣ) = x ln(ab)=ln a+ln b · ln(a/b)=ln a−ln b ln(aⁿ) = n·ln a · log_a x = ln x/ln a
อนุพันธ์ exp/log (eˣ)' = eˣ (aˣ)' = aˣ ln a
(ln x)' = 1/x (log_a x)' = 1/(x ln a)
ปริพันธ์ที่เจอบ่อย ∫1/x dx = ln|x|+C
∫1/(1+x²) dx = arctan x + C
∫1/√(1−x²) dx = arcsin x + C
ตรีโกณผกผัน (อนุพันธ์) (arcsin x)' = 1/√(1−x²)
(arccos x)' = −1/√(1−x²)
(arctan x)' = 1/(1+x²) ค่า: arcsin1=π/2, arctan1=π/4
ไฮเพอร์โบลิก sinh x=(eˣ−e⁻ˣ)/2 · cosh x=(eˣ+e⁻ˣ)/2 cosh²x − sinh²x = 1
(sinh)'=cosh · (cosh)'=sinh · (tanh)'=sech²x
เทคนิคเด็ด: log diff เจอ xˣ หรือฐาน/เลขชี้เป็นตัวแปร → ใส่ ln สองข้างก่อนค่อยดิฟ y=xˣ → ln y=x ln x → y'=xˣ(ln x+1)
กับดักที่ออกบ่อย • (aˣ)' ≠ x·aˣ⁻¹ (นั่นคือกฎกำลัง ใช้กับ xⁿ) • แก้สมการ log ต้องเช็คโดเมน (ตัวใน log > 0) • arccos' ติดลบ, arcsin' บวก
