① จลนศาสตร์ 5 ข้อ · เก็บฟรี

v = u + at  ·  s = ut + ½at²  ·  v² = u² + 2as  ·  s = ½(u+v)t
  • โจทย์บอกอะไรมา 3 ตัว → เลือกสูตรที่ไม่มีตัวที่โจทย์ไม่ถาม (นี่คือเทคนิคทั้งหมดของบทนี้)
  • กราฟ v–t: ความชัน = ความเร่ง · พื้นที่ใต้กราฟ = การกระจัด
  • ตกอิสระ: u = 0, a = g = 9.8 (หรือ 10) m/s² · ขึ้นสูงสุด v = 0
  • โพรเจกไทล์: แกน x กับ y คิดแยกกัน เวลาเท่านั้นที่ใช้ร่วม · x: a=0 · y: a=−g
กับดัก: ทิศทาง! ขึ้นเป็นบวก ลงเป็นลบ ต้องเลือกแล้วใช้ให้ตลอดข้อ

② แรงและกฎนิวตัน 5 ข้อ

ΣF = ma  ·  fs,max = μsN  ·  fk = μkN  ·  W = mg
  • วาด free-body diagram ก่อนเสมอ แล้วค่อยแตกแรงตามแกน
  • พื้นเอียงมุม θ: ขนานพื้น = mg sin θ · ตั้งฉากพื้น = mg cos θ → N = mg cos θ
  • ลิฟต์: ขึ้นเร่ง → N = m(g+a) หนักขึ้น · ลงเร่ง → N = m(g−a) เบาลง
  • เชือกพาดรอก มวล m₁ m₂: a = (m₁−m₂)g / (m₁+m₂)
กับดัก: N ไม่ได้เท่ากับ mg เสมอ! บนพื้นเอียงหรือในลิฟต์ต้องคิดใหม่ทุกครั้ง

③ โมเมนตัม 3 ข้อ

p = mv  ·  J = FΔt = Δp  ·  Σpก่อน = Σpหลัง
  • โมเมนตัมอนุรักษ์เสมอในการชน (ถ้าไม่มีแรงภายนอก) — ใช้ได้ทั้งยืดหยุ่นและไม่ยืดหยุ่น
  • ชนแบบยืดหยุ่น → พลังงานจลน์อนุรักษ์ด้วย
  • ชนแบบไม่ยืดหยุ่นสมบูรณ์ → ติดกันไปด้วยกัน: m₁u₁ + m₂u₂ = (m₁+m₂)v
กับดัก: โมเมนตัมเป็นเวกเตอร์ — ชนคนละทิศต้องใส่เครื่องหมายลบ

④ งานและพลังงาน 5 ข้อ

W = Fd cos θ  ·  KE = ½mv²  ·  PE = mgh  ·  P = W/t = Fv
  • อนุรักษ์พลังงานกล: KE + PE คงที่ (ถ้าไม่มีแรงเสียดทาน) → ½mu² + mgh₁ = ½mv² + mgh₂
  • งาน–พลังงานจลน์: Wรวม = ΔKE
  • สปริง: PE = ½kx²
กับดัก: θ ใน W = Fd cos θ คือมุมระหว่างแรงกับการกระจัด ไม่ใช่มุมพื้นเอียง · แรงตั้งฉากกับการเคลื่อนที่ ทำงาน = 0 (เช่น แรง N, แรงสู่ศูนย์กลาง)

⑤ คลื่นกล 5 ข้อ

v = fλ  ·  T = 1/f  ·  fบีต = |f₁ − f₂|
  • คลื่นนิ่ง: ระยะระหว่างปมถึงปมถัดไป = λ/2 (ไม่ใช่ λ)
  • เส้นเชือก/ท่อปลายเปิดสองด้าน: L = nλ/2 → f = nv/2L
  • ท่อปลายปิดข้างเดียว: L = nλ/4 (n เป็นเลขคี่เท่านั้น)
  • ดอปเพลอร์: เข้าหากัน → ความถี่สูงขึ้น · ห่างออก → ต่ำลง
กับดัก: เปลี่ยนตัวกลาง → ความถี่คงเดิมเสมอ ที่เปลี่ยนคือ v กับ λ

⑥ แสง 5 ข้อ

n₁ sin θ₁ = n₂ sin θ₂  ·  1/f = 1/u + 1/v  ·  m = −v/u  ·  n = c/v
  • มุมวัดจากเส้นปกติ (เส้นตั้งฉากผิว) ไม่ใช่จากผิว
  • มุมวิกฤต: sin θc = n₂/n₁ — เกิดสะท้อนกลับหมดได้เมื่อไปจากตัวกลางหนาแน่นกว่า → บางกว่าเท่านั้น
  • เลนส์นูน/กระจกเว้า f เป็นบวก · เลนส์เว้า/กระจกนูน f เป็นลบ
  • ภาพจริงหัวกลับ (m ติดลบ) · ภาพเสมือนหัวตั้ง (m เป็นบวก)
กับดัก: เครื่องหมาย! จำสั้น ๆ ว่า ภาพจริงอยู่คนละฝั่งกับวัตถุ แล้วเซ็ตเครื่องหมายตามนั้น

⑦ ไฟฟ้ากระแสตรง 6 ข้อ · เยอะสุดในโซนเขียว

V = IR  ·  P = VI = I²R = V²/R  ·  E = I(R + r)
  • อนุกรม: Rรวม = R₁+R₂ · กระแสเท่ากันทุกตัว · แรงดันแบ่งกัน
  • ขนาน: 1/Rรวม = 1/R₁ + 1/R₂ · แรงดันเท่ากันทุกตัว · กระแสแบ่งกัน
  • สองตัวขนาน ใช้สูตรลัด: R = R₁R₂/(R₁+R₂)
  • Kirchhoff: ที่จุดต่อ กระแสเข้า = กระแสออก · รอบวงปิด ผลรวมแรงดัน = 0
  • วีตสโตนสมดุล (ไม่มีกระแสผ่านกัลวานอมิเตอร์): R₁/R₂ = R₃/R₄
  • แอมมิเตอร์ต่ออนุกรม (ความต้านทานต่ำ) · โวลต์มิเตอร์ต่อขนาน (ความต้านทานสูง)
กับดัก: ถ้าโจทย์มี r (ความต้านทานภายในแบตเตอรี่) อย่าลืมบวก — แรงดันที่วัดได้จริงคือ V = E − Ir ไม่ใช่ E
🔴 คืนนี้ข้ามไปเลย ไม่ต้องเสียดาย — อุณหพลศาสตร์ (8 ข้อ) และ การเหนี่ยวนำ/RLC (5 ข้อ) รวม 13 ข้อ = 15% ของข้อสอบ ใช้เวลาเยอะแต่ได้น้อย
🟡 ถ้าเหลือเวลาค่อยแตะ SHM (T = 2π√(m/k), T = 2π√(L/g)) กับ ของไหล (P = ρgh, แรงลอยตัว = ρของเหลวVg)
