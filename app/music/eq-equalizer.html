🎚️ EQ (Equalizer) ทำงานยังไง — ลองปรับเอง

ตัวนี้ใช้ Web Audio API ของเบราว์เซอร์จริง ๆ (BiquadFilterNode ตัวเดียวกับ EQ มืออาชีพ) เปิดเสียง แล้วลากสไลเดอร์ดูว่าเสียง + กราฟเปลี่ยนยังไง

เลือกแหล่งเสียงด้านบนก่อน แล้วกด ▶ เล่น
แกนนอน = ความถี่ (ต่ำ→สูง) · แกนตั้ง = ความดัง
สเปกตรัมเสียงจริง (real-time) เส้นโค้ง EQ ที่คุณตั้ง (เพิ่ม/ลดตรงไหน) เส้น 0 dB (ไม่ปรับ)
พรีเซ็ต:

ลากขึ้น = boost (ดังขึ้น), ลากลง = cut (เบาลง). ค่าหน่วยเป็น dB

EQ ทำงานยังไง? (อ่านหลังจากลองเล่นแล้ว)

เสียงทุกเสียง = คลื่นหลาย ความถี่ (Hz) รวมกัน EQ คือการ "เพิ่ม/ลดความดัง" ของแต่ละย่านความถี่แยกกัน

แต่ละย่านในนี้:

60 Hz — เบสลึก 170 Hz — เบส/ความอิ่ม 350 Hz — กลางต่ำ 1 kHz — กลาง/เสียงร้อง 3.5 kHz — ความใส/ชัด 10 kHz — แหลม/ความเปิด

ข้างในใช้ filter 3 ชนิด: ย่านล่างสุดเป็น lowshelf (ยก/ลดทุกอย่างที่ต่ำกว่าจุดนั้น), ย่านบนสุดเป็น highshelf, ย่านกลางเป็น peaking (ยก/ลดเป็นเนินโค้งรอบความถี่นั้น)

filter แต่ละตัวมีพารามิเตอร์หลัก: frequency (ปรับย่านไหน), gain (กี่ dB — สไลเดอร์คุมตัวนี้), Q (เนินแคบหรือกว้าง). สัญญาณเสียงวิ่งผ่าน filter ต่อกันเป็นทอด ๆ source → 60Hz → 170Hz → ... → 10kHz → ลำโพง

👉 ลองกด "EQ: เปิด/ปิด" สลับไปมาเพื่อได้ยินผลต่างชัด ๆ และดูเส้นสีฟ้าเทียบกับเส้น 0 dB

โค้ดหัวใจหลัก (เผื่ออยากเอาไปทำต่อ)

หัวใจคือการสร้าง filter แล้วต่อสายสัญญาณ:

const ctx = new AudioContext();
const f = ctx.createBiquadFilter();
f.type = "peaking";        // หรือ lowshelf / highshelf
f.frequency.value = 1000;  // ย่าน 1 kHz
f.Q.value = 1;             // ความกว้างของเนิน
f.gain.value = 6;          // +6 dB (สไลเดอร์คุมค่านี้)

source.connect(f);         // ต่อสายสัญญาณ
f.connect(ctx.destination);// ออกลำโพง
