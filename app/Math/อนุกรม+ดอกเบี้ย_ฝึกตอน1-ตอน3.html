📐 สูตรที่ห้องสอบแจกให้

อาจารย์บอกว่ามีสูตรให้ — ที่ต้องฝึกคือเลือกสูตรให้ถูกกับโจทย์ ไม่ใช่ท่องสูตร

ลำดับและอนุกรมเลขคณิต

หาสูตรใช้เมื่อ
พจน์ที่ nan = a₁ + (n−1)dรู้ a₁ กับ d
ผลบวก n พจน์Sn = n2(a₁ + an)รู้พจน์แรกกับพจน์สุดท้าย
ผลบวก n พจน์Sn = n2[2a₁ + (n−1)d]รู้ a₁ กับ d แต่ไม่รู้พจน์สุดท้าย
จำนวนพจน์n = an − a₁d + 1รู้พจน์แรก พจน์สุดท้าย และ d

ลำดับและอนุกรมเรขาคณิต

หาสูตรใช้เมื่อ
พจน์ที่ nan = a₁rn−1รู้ a₁ กับ r
ผลบวก n พจน์Sn = a₁(rn − 1)r − 1r ≠ 1
ผลบวกอนันต์S∞ = a₁1 − rใช้ได้เมื่อ |r| < 1 เท่านั้น
