1.1 ตัวแปรสุ่ม คืออะไร [A p.1–3]

ตัวแปรสุ่ม (random variable) = ฟังก์ชัน จากปริภูมิตัวอย่าง S → ไปยังเซตของจำนวนจริง
มันไม่ใช่ “ตัวแปร” ธรรมดา แต่เป็น กฎแปลงผลลัพธ์ให้เป็นเลข เช่น “หัว‑ก้อย” → “จำนวนหัว”

ชนิดนิยามตัวอย่าง
ไม่ต่อเนื่อง (discrete)ค่าที่เป็นไปได้ นับได้ (เซตจำกัด หรืออนันต์ ก็ได้)จำนวนข้อถูก, จำนวนคน, แต้มลูกเต๋า
ต่อเนื่อง (continuous)ค่าที่เป็นไปได้เป็น ช่วง (สับเซตของ ℝ)ความสูง, น้ำหนัก, เวลา, อุณหภูมิ

หลักจำ: นับ (count) = ไม่ต่อเนื่อง / วัด (measure) = ต่อเนื่อง

1.2.1 การแจกแจงเอกรูปไม่ต่อเนื่อง (Discrete Uniform) [B p.1–5]

P(X=xi) = 1n  ทุก iเมื่อ “ทุกค่ามีโอกาสเท่ากันหมด”
“ยุติธรรมเท่ากันทุกหน้า” เช่น ลูกเต๋าเที่ยงตรง 1 ลูก → แต่ละแต้ม = 1/6
“เอกรูป” ดูที่ ความน่าจะเป็นเท่ากัน ไม่ใช่ค่าของตัวแปรเท่ากัน · ระวังเมื่อหลายผลลัพธ์รวมเป็นค่าเดียว เช่น “จำนวนก้อยใน 10 ครั้ง” → P(0)=(½)¹⁰ ≠ P(5)=C(10,5)(½)¹⁰ → ไม่เอกรูป
🔑 ตัวอย่าง — สลาก 4 ใบ {20,50,100,500} บาท [B p.2] แต่ละใบโอกาส 1/4 → เอกรูป ✓
E(X) = (20+50+100+500)/4 = 670/4 = 167.5 บาท
ถ้าค่าตั๋ว 150 → 167.5 − 150 = +17.5 → ได้เปรียบ
ลัดเอกรูป: E(X) = ค่าเฉลี่ยเลขคณิตธรรมดาของทุกค่า (เพราะถ่วงน้ำหนักเท่ากันหมด)

1.2.2 การแจกแจงทวินาม (Binomial) ⭐⭐ หัวใจของบท [B p.6–12]

เงื่อนไข 3 ข้อ จึงเรียก “ทวินาม”

  1. ทดลองสุ่ม n ครั้ง อิสระต่อกัน (ครั้งก่อนไม่กระทบครั้งหลัง)
  2. แต่ละครั้งมีผลแค่ 2 แบบ: สำเร็จ / ไม่สำเร็จ
  3. ความน่าจะเป็นสำเร็จ คงที่ = p ทุกครั้ง (ไม่สำเร็จ = 1−p), 0<p<1

เขียนย่อ X ~ B(n, p) · แก่นแท้: “ทำซ้ำเหตุการณ์เบอร์นูลลี n ครั้ง แล้วนับจำนวนครั้งที่สำเร็จ”

ทฤษฎีบท — สูตรทวินาม 3 ตัว

P(X=x) = (nx) px (1−p)n−x  ,  x = 0,1,2,…,n
μX = np
σX2 = np(1−p)
• pˣ = สำเร็จ x ครั้ง · (1−p)ⁿ⁻ˣ = ไม่สำเร็จที่เหลือ · C(n,x) = เลือกว่าครั้งไหนสำเร็จได้กี่แบบ
• μ=np ตรงสามัญสำนึก: โยนเหรียญ 10 ครั้ง p=½ → เฉลี่ยได้หัว 5 ครั้ง
• ✅ ผลรวม: Σ P(X=x) = [p+(1−p)]ⁿ = 1ⁿ = 1 (ทฤษฎีบททวินาม)

📋 กฎพีชคณิตของ E และ Var [C p.1, p.8]

กฎค่าคาดหมาย E

กฎสูตรตัวอย่าง
ค่าคงที่E(a) = aE(5)=5
คูณค่าคงที่E(aXᵏ) = a·E(Xᵏ)E(3X)=3E(X)
ฟังก์ชันของ XE[g(X)] = Σ g(xᵢ)·P(xᵢ)E(3X+2)=Σ(3xᵢ+2)P
บวก/ลบ & เชิงเส้นE(aX+b) = a·E(X) + bE(y±z)=E(y)±E(z)
🔑 ให้ E(X)=3, E(X²)=25 [C p.2–3] ก) E(2X+4) = 2E(X)+4 = 2(3)+4 = 10
ข) E[X−E(X)]² = E(X²) − [E(X)]² = 25 − 9 = 16 ← นี่คือ ความแปรปรวน นั่นเอง

กฎความแปรปรวน Var

กฎสูตรเหตุผล (แก่น)
ค่าคงที่Var(a)=0ค่าคงที่ไม่กระจาย
คูณค่าคงที่Var(aX)=a²·Var(X)ขยาย a เท่า → กระจาย a² เท่า
บวกค่าคงที่Var(aX+b)=a²·Var(X)+b เลื่อนตำแหน่ง ไม่เพิ่มการกระจาย
จุดพลาดคลาสสิก: บวกค่าคงที่ b ไม่กระทบความแปรปรวน (+b หาย) แต่ กระทบค่าคาดหมาย (+b ติดมา) — สองสูตรนี้คนละพฤติกรรม
🔑 ให้ Var(X)=10 [C p.9] ก) Var(2X+1) = 2²·Var(X) = 4(10) = 40 · ข) Var(3X+4) = 3²·Var(X) = 9(10) = 90

🎯 ข้อสอบจริง (คณิต1 เม.ย.64) [A p.16]

สลาก 9 ใบ {1..9} หยิบพร้อมกัน 2 ใบ จ่าย 90 บาท · ผลคูณ คู่ → ได้ 180 · ผลคูณ คี่ → ไม่ได้อะไร

วิธีทำ (แก่น = หา P ของเหตุการณ์ก่อน)
ผลคูณ คี่ ก็ต่อเมื่อ ทั้งสองใบคี่ → เลขคี่ {1,3,5,7,9} มี 5 ตัว
P(คี่) = C(5,2)/C(9,2) = 10/36 = 5/18 → P(คู่) = 13/18
กำไรสุทธิ: คู่ → +90, คี่ → −90
E = 90·(13/18) − 90·(5/18) = 90·(8/18) = 90·(4/9) = +40
ตอบ ข้อ 2: โดยเฉลี่ยได้กำไรครั้งละ 40 บาท ✓

10โจทย์เกม/ประกัน ตอบผิดทิศหา E(กำไรสุทธิ) แล้วดูเครื่องหมาย +/0/−

🧪 สูตรรวบยอด (Cheat box)

ค่าคาดหมาย μ = E(X) = Σ xᵢ·P(X=xᵢ) ความแปรปรวน σ² = Σ(xᵢ−μ)²·P = E(X²) − μ² [สูตรลัด] ส่วนเบี่ยงเบนฯ σ = √σ² เชิงเส้น E(aX+b) = aE(X)+b Var(aX+b) = a²·Var(X) เอกรูป (n ค่า) P = 1/n E = ค่าเฉลี่ยเลขคณิตของทุกค่า ทวินาม B(n,p) P(X=x)=C(n,x)pˣ(1−p)ⁿ⁻ˣ μ = np σ² = np(1−p) σ = √(np(1−p))
