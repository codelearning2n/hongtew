📈 ตัวแปรสุ่มต่อเนื่อง & การแจกแจงปกติ

สื่อการสอนโต้ตอบ ม.6 — จากต้นตอ: ทำไมต้องใช้ "พื้นที่ใต้โค้ง" จนถึงข้อสอบเข้ามหาลัยจริง
ลากสไลเดอร์ จิ้มกราฟ จิ้มตาราง — ลองผิดลองถูกได้เต็มที่ 🎮

ทำไมตัวแปรสุ่ม "ต่อเนื่อง" ใช้ตารางแบบเดิมไม่ได้?

บทก่อนหน้า ตัวแปรสุ่มไม่ต่อเนื่อง (เช่น แต้มลูกเต๋า) มีค่าที่นับได้ → เขียนตารางแจกแจงความน่าจะเป็นได้ แต่... จิ้มการ์ด 2 ใบนี้ดูความต่าง 👇

🎲 ไม่ต่อเนื่อง (Discrete) — แต้มลูกเต๋า, จำนวนหัวจากการโยนเหรียญ
ค่าที่เป็นไปได้: 1,2,3,4,5,6 — นับได้ → ทำตาราง X กับ P(X) ได้สบาย เช่น P(X=3)=1/6
📏 ต่อเนื่อง (Continuous) — ส่วนสูง, น้ำหนักผู้ป่วย, เวลาที่ลูกค้าใช้ในห้าง [ชีท p.1]
ค่าที่เป็นไปได้เป็นช่วง ซึ่งเป็นสับเซตของจำนวนจริง เช่น สูง 160 ซม., 160.1, 160.05, 160.0001... มีสมาชิกอนันต์ → เขียนตารางไม่ไหว! ต้องใช้เครื่องมือใหม่: เส้นโค้งความหนาแน่น (density curve)

🧪 ทดลอง: จากฮิสโทแกรม → เส้นโค้งความหนาแน่น

📜 กติกาของฟังก์ชันความหนาแน่น f(x)

เส้นโค้งความหนาแน่นคือกราฟ y = f(x) เรียก f ว่า ฟังก์ชันความหนาแน่นความน่าจะเป็น (probability density function) [ชีท p.1] ต้องผ่าน 2 เงื่อนไข:

① f(x) ≥ 0 ทุกค่า x     ② พื้นที่ใต้โค้งทั้งหมด = 1
P(1 < X < 3) = ∫13 f(x) dx = พื้นที่ใต้โค้งช่วง 1 ถึง 3

แปลไทยเป็นไทย: "ความน่าจะเป็น = พื้นที่ใต้โค้ง" ประโยคเดียวจบ — ทั้งบทนี้คือการหาพื้นที่ใต้โค้งให้เป็น 🎯

🔔 การแจกแจงปกติ (Normal Distribution)

เส้นโค้งความหนาแน่นที่เจอบ่อยสุดในธรรมชาติ: รูประฆังสมมาตร เช่น ความสูงประชากรไทย, คะแนน O-NET, อายุใช้งานสินค้า [ชีท p.2] เขียนแทนด้วย X ~ N(μ, σ²) — ระวัง! ตัวหลังคือความแปรปรวน σ² ไม่ใช่ σ

ลองลาก μ กับ σ ดูสิ — อะไรคุมตำแหน่ง อะไรคุมความอ้วน? (เส้นเทาจางคือเส้นเดิม N(160, 5²) ไว้เทียบ)

✅ สมบัติของเส้นโค้งปกติ [ชีท p.2-3]

จิ้มทีละข้อเพื่อดูคำอธิบาย:

1️⃣ สมมาตรรอบเส้นตั้งฉากที่ผ่าน ค่าเฉลี่ย μ
พื้นที่ซ้ายของ μ = พื้นที่ขวาของ μ = 0.5 พอดี → P(X > μ) = 0.5 เสมอ (ใช้บ่อยมากตอนทำข้อสอบ)
2️⃣ ปลายโค้งเข้าใกล้แกน X แต่ไม่ตัด
แกน X เป็นเส้นกำกับแนวนอน (horizontal asymptote) — โค้งยาวไปถึง ±∞ แค่ต่ำมากๆ
3️⃣ μ และ σ กำหนดลักษณะเฉพาะของโค้ง
μ บอกว่าแกนสมมาตรอยู่ไหน · σ (หรือ σ²) บอกว่ากระจายจากค่าเฉลี่ยมากแค่ไหน — สองตัวนี้เรียกว่า พารามิเตอร์ ของการแจกแจงปกติ

📏 การแจกแจงปกติมาตรฐาน (Standard Normal)

ปัญหา: โค้งปกติมีได้อนันต์แบบ (μ, σ ใดก็ได้) จะทำตารางพื้นที่ทุกแบบไม่ไหว → เลยตกลงใช้ "โค้งกลาง" ตัวเดียว: บทนิยาม 6 [ชีท p.4]: การแจกแจงปกติที่มี μ = 0 และ σ = 1 เรียกตัวแปรสุ่มนี้ว่า Z แล้วทำตารางพื้นที่ไว้ให้เปิด

ตารางบอกค่า P(Z ≤ z) = พื้นที่ใต้โค้งจาก −∞ ถึง z

🧰 4 ท่าไม้ตาย แปลงทุกโจทย์ให้เปิดตารางได้

ตารางให้แค่ P(Z ≤ z) แต่โจทย์ถามได้ 4 แบบ — จิ้มดูวิธีแปลง:

① P(Z ≤ z) — น้อยกว่า
เปิดตารางตรงๆ จบ ✅
② P(Z ≥ z) — มากกว่า
พื้นที่ทั้งหมด = 1 → P(Z ≥ z) = 1 − P(Z ≤ z)
③ P(a ≤ Z ≤ b) — ระหว่าง
พื้นที่ใหญ่ลบพื้นที่เล็ก → P(a ≤ Z ≤ b) = P(Z ≤ b) − P(Z ≤ a)
④ ใช้ความสมมาตร
P(Z ≤ −z) = P(Z ≥ z) = 1 − P(Z ≤ z) — โค้งซ้ายขวาเหมือนกันเป๊ะ ตารางบางฉบับให้เฉพาะ z บวก ต้องใช้ท่านี้

✏️ ฝึกจากตัวอย่างที่ 1 ในชีท [p.7]

🔄 ทฤษฎีบท 2 — สะพานเชื่อมโลกจริงกับตาราง Z [ชีท p.8]

โจทย์จริงไม่ได้ให้ Z มา แต่ให้ X ~ N(μ, σ²) เช่น ส่วนสูง N(160, 25) — ตารางที่ 1 ใช้ตรงๆ ไม่ได้ ต้องแปลงให้เป็นมาตรฐานก่อนด้วยสูตรเดียว:

Z = X − μσ   แล้ว Z ~ N(0, 1) เสมอ
ความหมายจริงๆ ของ z: "ห่างจากค่าเฉลี่ยกี่เท่าของ σ" — z = +2 คือสูงกว่าเฉลี่ย 2 SD, z = −1.5 คือต่ำกว่าเฉลี่ย 1.5 SD → ใช้เทียบข้อมูลคนละชุดกันได้ (ดูแท็บ 5)
