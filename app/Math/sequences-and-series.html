1. ลำดับ (Sequence)

นิยาม

ลำดับ คือ การนำสิ่งต่างๆ มาเรียงอย่างมีลำดับ แต่ละตัวเรียกว่า "พจน์" (term)

a₁ = พจน์ที่ 1, a₂ = พจน์ที่ 2, ..., aₙ = พจน์ทั่วไป (general term)

📂ประเภทของลำดับ

ลำดับจำกัด (Finite)

มีจำนวนพจน์จำกัด

7, 14, 21, 28, 35, 42

ลำดับอนันต์ (Infinite)

ต่อไปเรื่อยๆ ไม่สิ้นสุด

6, 11, 16, 21, ..., 5n+1, ...

✏️การเขียนลำดับ 2 วิธี

1
แจกแจงพจน์ 3, 5, 7, 9, ...
2
พจน์ทั่วไป aₙ = 2n + 1

เครื่องคำนวณพจน์ทั่วไป

ใส่สูตร aₙ แล้วหาค่า (ใช้ n เป็นตัวแปร, ** = ยกกำลัง)

ผลลัพธ์จะแสดงที่นี่

หาพจน์ทั่วไป

ลำดับ: 3, 5, 7, 9, ...

📝 ตัวอย่างจาก PDF (ตัวอย่างที่ 1-5)▼

ตัวอย่าง 2: aₙ = 2n² − 3n → a₁ = −1, a₂ = 2

ตัวอย่าง 3: ลำดับ 3,5,7,9,... → aₙ = 2n+1

ตัวอย่าง 5: aₙ = 2n+3, 29 เป็นพจน์ที่ → n=13

2.1 ลำดับเลขคณิต (Arithmetic Sequence)

นิยาม

ลำดับเลขคณิต (AP) คือ ลำดับที่ผลต่างระหว่างพจน์ติดกันคงที่ → "ผลต่างร่วม" d = aₙ₊₁ − aₙ

สูตรพจน์ทั่วไป
an=a1+(n−1)d

📊Visualization

💡คุณสมบัติสำคัญ

ถ้า a, b, c เป็น AP → b = (a+c)/2 (มัชฌิมเลขคณิต)

Tip: ตั้ง 3 พจน์ AP = a−d, a, a+d (ผลบวก = 3a)

เครื่องคำนวณลำดับเลขคณิต

📝 ตัวอย่างที่ 6-18▼

ตัวอย่าง 9: AP 100,97,94,... → a₂₁ = 100+20(−3) = 40

ตัวอย่าง 12: a₄=20, a₁₀=38 → d=3, aₙ = 3n+8

ตัวอย่าง 13: x, 2x−1, x+8 เป็น AP → x=5, d=4

ตัวอย่าง 17: 100-500 หาร 7 ลงตัว → 57 จำนวน

❓ทดสอบ

AP: 5, 9, 13, 17, ... พจน์ที่ 20 = ?

2.2 ลำดับเรขาคณิต (Geometric Sequence)

นิยาม

ลำดับเรขาคณิต (GP) คือ ลำดับที่อัตราส่วนระหว่างพจน์ติดกันคงที่ → "อัตราส่วนร่วม" r = aₙ₊₁/aₙ

สูตรพจน์ทั่วไป
an=a1⋅rn−1

📊Visualization

💡คุณสมบัติ

ถ้า a, b, c เป็น GP → b² = a·c (มัชฌิมเรขาคณิต)

เครื่องคำนวณ GP

📝 ตัวอย่างที่ 19-31▼

ตัวอย่าง 27: x−2, 2x−3, 5x−6 เป็น GP → x=3 หรือ −1

ตัวอย่าง 31: ลูกบอลตก 6400m กระดอน ½ → ครั้งที่ 10 สูง 6.25 m

❓ทดสอบ

GP: 2, 6, 18, 54, ... พจน์ที่ 7 = ?

2.3 ลำดับฮาร์มอนิก (Harmonic Sequence)

นิยาม

ลำดับฮาร์มอนิก (HP) คือ ลำดับที่ ส่วนกลับ (1/aₙ) ของแต่ละพจน์เป็นลำดับเลขคณิต

📖ตัวอย่าง

HP: 1, 1/2, 1/3, 1/4, ...

ส่วนกลับ: 1, 2, 3, 4, ... → AP (d=1) ✓

HP: 1/2, 1/5, 1/8, 1/11, ...

ส่วนกลับ: 2, 5, 8, 11, ... → AP (d=3) ✓

มัชฌิมฮาร์มอนิก
H=2aca+c

ตรวจสอบลำดับฮาร์มอนิก

3. สัญลักษณ์แสดงการบวก (Sigma Notation)

นิยาม
nΣi=1 aᵢ = a₁ + a₂ + ... + aₙ

📋สมบัติของ Sigma

1. Σ(aᵢ ± bᵢ) = Σaᵢ ± Σbᵢ
2. Σ(c·aᵢ) = c·Σaᵢ
3. Σc = nc (c = ค่าคงที่)

📐สูตรผลรวมที่ใช้บ่อย

Σi = n(n+1)/2
Σi² = n(n+1)(2n+1)/6
Σi³ = [n(n+1)/2]²

เครื่องคำนวณ Sigma

4. ลิมิตของลำดับอนันต์

นิยาม

ถ้า aₙ เข้าใกล้ L เมื่อ n → ∞ → lim(n→∞) aₙ = L

ลู่เข้า (converge) = มีลิมิต | ลู่ออก (diverge) = ไม่มีลิมิต

📐ทฤษฎี 7 ข้อ

1. lim(1/nᵏ) = 0 (k>0)
2.r|<1 → lim rⁿ=0 | |r|>1 → ลู่ออก
3. lim(aₙ±bₙ)=A±B, lim(aₙ·bₙ)=A·B, lim(aₙ/bₙ)=A/B
4. lim bₙ=±∞ → lim(c/bₙ)=0
5. เศษส่วนพหุนาม: deg เศษ < deg ส่วน→0, เท่ากัน→สปส.นำ/สปส.นำ, มากกว่า→±∞
6. ลำดับสลับ: lim|aₙ|=0 → ลู่เข้าสู่ 0
7. ถ้า aₙ คอนเวอร์เจนต์: lim aₙ = lim aₙ₊₁

5. อนุกรม (Series)

นิยาม

อนุกรม = ผลบวกของพจน์ในลำดับ → Sₙ = a₁ + a₂ + ... + aₙ

ผลบวก n พจน์แรก (AP)
Sn=n2(a1+an)=n2[2a1+(n−1)d]

อนุกรมเลขคณิต

Sn=a1(rn−1)r−1 เมื่อ r≠1

อนุกรม Telescopic

อนุกรมที่พจน์ติดกันหักล้างกันไปเรื่อยๆ

📖เศษส่วนย่อย

1/(n(n+1)) = 1/n − 1/(n+1)
1/((2n−1)(2n+1)) = ½(1/(2n−1) − 1/(2n+1))

Σ 1/(i·(i+1)), i=1 ถึง n

6. อนุกรมอนันต์ (Infinite Series)

นิยาม

อนุกรมเรขาคณิตอนันต์ ลู่เข้า ก็ต่อเมื่อ |r| < 1

ทฤษฎี: ถ้า Σaₙ ลู่เข้า → lim aₙ = 0 (จำเป็นแต่ไม่เพียงพอ)

ผลบวกอนุกรมเรขาคณิตอนันต์
S∞=a11−r

ใช้ได้เมื่อ |r| < 1

🔄ทศนิยมซ้ำ → เศษส่วน

0.333... = 3/10 + 3/100 + ... → a₁=3/10, r=1/10 → S∞ = 1/3

📋อนุกรมผสม

ถ้า Σaₙ = AP, Σbₙ = GP ลู่เข้า → Σ(aₙ·bₙ) จะลู่เข้า

ผลบวกอนุกรมอนันต์

71.11: Σ 2/(−3)ⁿ → S∞ = −1/2

Compound Interest
A=P(1+rm)mt

📈PV & FV

Present Value
PV=FV(1+rm)mt
Future Value
